# Support

ThreadRunner is an early-stage, local-first open-source project. It does not currently offer a hosted service, managed setup, or guaranteed response time.

## Questions and setup help

Use a GitHub issue for:

- Setup questions
- Documentation improvements
- Reproducible bugs
- Feature proposals

Please search existing issues first and use the relevant issue template when available.

## Security reports

Do **not** report suspected vulnerabilities in a public issue.

See [SECURITY.md](SECURITY.md) for the security policy, supported reporting path, and the project's threat model.

## Scope

ThreadRunner is intended to be a personal, self-hosted control plane for local coding-agent CLIs. It is not a general remote shell, multi-tenant service, or provider-subscription proxy.
